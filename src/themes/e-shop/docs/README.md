# E-shop Theme Documentation

## Overview

E-commerce theme with product grids, category pages, and shopping functionality.

---

## Design System

### Tokens

Uses the canonical design token set with theme-specific overrides. See `theme.css` for the full token set.

### Components

Registry entries in `src/config/designSystemRegistry.ts`:
- Header, Footer, Category Header
- Large Hero
- Product Grid
- FiftyFifty Section, Product Carousel, OneThirdTwoThirds Section, Editorial Section

---

## Pages and Routing

See `pages.json` for registered pages.

---

## Asset Conventions

### Static (git) assets

- Location: `src/themes/e-shop/assets/`
- Served at: `/theme/e-shop/assets/<file>`
