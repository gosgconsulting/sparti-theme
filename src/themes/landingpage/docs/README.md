# Landingpage Theme Documentation

## Overview

ACATR Business Services landing page theme with hero, services, testimonials, FAQ, and CTA sections.

---

## Design System

### Tokens

Uses the canonical design token set with theme-specific overrides. See `theme.css` for the full token set.

### Components

Registry entries in `src/config/designSystemRegistry.ts`:
- Header, Footer
- Hero Section
- Services Section, Testimonials Section, FAQ Section, CTA Section
- Contact Form Dialog

---

## Pages and Routing

See `pages.json` for registered pages.

---

## Asset Conventions

### Static (git) assets

- Location: `src/themes/landingpage/assets/`
- Served at: `/theme/landingpage/assets/<file>`
